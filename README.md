# 🏡 Farm Case — نظام متابعة المزارع

نظام إدارة وتتبع حالات المزارع، مبني بـ **React + Vite + Firebase**.

---

## 📁 هيكل المشروع

```
farm-case-web/
├── index.html                  ← نقطة الدخول الرئيسية
├── vite.config.js              ← إعدادات Vite
├── package.json                ← المتطلبات والأوامر
├── .env                        ← متغيرات البيئة (Firebase - لا تُرفع لـ Git)
├── .env.example                ← نموذج متغيرات البيئة
│
└── src/
    ├── main.jsx                ← نقطة دخول React
    ├── App.jsx                 ← التوجيه بين الصفحات + بنية التطبيق
    ├── index.css               ← نظام التصميم الكامل (Tokens + Utilities)
    │
    ├── core/                   ← المنطق الأساسي المشترك
    │   ├── auth.js             ← تسجيل الدخول / الخروج / إدارة المستخدم
    │   ├── firebase.js         ← الاتصال بـ Firebase (قراءة/كتابة)
    │   ├── conditions.js       ← قواعد الحالات + بناء نص الكليشة
    │   └── utils.js            ← دوال مساعدة (الوقت، الشفت، ...)
    │
    └── components/
        ├── LoginPage.jsx       ← صفحة تسجيل الدخول
        │
        ├── shared/             ← مكونات مشتركة
        │   ├── Sidebar.jsx     ← الشريط الجانبي + قائمة الحساب
        │   └── Toast.jsx       ← نظام الإشعارات (Toast)
        │
        ├── app/                ← صفحات المستخدم العادي
        │   ├── CasePage.jsx    ← تسجيل حالة جديدة (الصفحة الرئيسية)
        │   ├── HistoryPage.jsx ← سجل الحالات السابقة
        │   ├── ProfilePage.jsx ← الملف الشخصي وإعدادات الإشعارات
        │   └── PersonalSettingsPage.jsx ← تخصيص المظهر
        │
        └── admin/              ← صفحات المدير فقط
            ├── AdminDashboard.jsx   ← لوحة الإحصائيات
            ├── UsersPage.jsx        ← إدارة الموظفين والصلاحيات
            ├── SettingsPage.jsx     ← إعدادات النظام (قواعد الحالات)
            └── MessagesPage.jsx     ← التحذيرات والرسائل
```

---

## 🚀 تشغيل المشروع

```bash
# تثبيت المتطلبات
npm install

# تشغيل وضع التطوير
npm run dev

# بناء النسخة النهائية
npm run build
```

---

## ⚙️ إعداد Firebase

انسخ ملف `.env.example` إلى `.env` وأضف بيانات Firebase الخاصة بك:

```bash
cp .env.example .env
```

---

## 🔑 أدوار المستخدمين

| الدور | الصلاحيات |
|-------|-----------|
| **مدير** (admin) | لوحة إحصائيات، إدارة موظفين، إعدادات النظام، جميع الصفحات |
| **موظف** (employee) | تسجيل حالة، عرض السجل، الملف الشخصي |

---

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|----------|
| **React 18** | بناء الواجهة |
| **Vite** | أداة البناء والتطوير |
| **Firebase Realtime DB** | قاعدة البيانات السحابية |
| **Vanilla CSS** | نظام التصميم |

---

## 📌 ملاحظات

- البيانات تُحفظ محلياً عند انقطاع الإنترنت وتتزامن فور العودة
- الصور الشخصية تُخزَّن في `localStorage`
- الكليشات تُنسَّخ بالعربية والإنجليزية بضغطة واحدة
